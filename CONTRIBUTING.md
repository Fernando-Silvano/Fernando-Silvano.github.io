# Contributing

Thank you for helping improve the Windows 95 Web Simulator.

## Before you start
- Read the [README](README.md) and check existing issues or pull requests.
- For a larger change, open an issue to discuss scope and compatibility first.
- Respect Microsoft trademarks and third-party asset licenses. Do not add proprietary operating-system binaries or copyrighted assets without permission.

## Development
1. Fork the repository and create a descriptive branch.
2. Run the site locally with `python -m http.server 8000` (or any static web server).
3. Open `http://localhost:8000`; the entry point is `index.html`.
4. Keep the project dependency-light, accessible, and usable with keyboard and pointer.
5. Verify startup, login, Start menu, window controls, included apps, and shutdown manually.
6. Include screenshots or reproduction steps when changes affect the interface.

## Pull requests
Explain what changed, why it helps, how it was tested, and any limitations. Keep unrelated changes separate. Do not include real passwords, tokens, or personal data.

## Issues
Provide browser/version, reproduction steps, expected behavior, actual behavior, and screenshots where helpful.

## Code of conduct
Be respectful and constructive in all discussions. Harassment and personal attacks are not welcome.
